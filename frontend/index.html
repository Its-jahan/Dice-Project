Watchlists

        
      

      

        

          Wallets that bought a token early, watched for what they buy next. Each run
          asks Dune what these wallets bought on DEXes inside the buy window; when
          enough of them bought the same token it becomes a signal below.

Cohort overlap

        

          
          
          
          
          
          
        

      

      

        

          Which watchlists share wallets — “the wallets that farmed X are now in Y”.
          Computed from data already stored, so it costs no Dune credits.
          Shared is the raw count, which on its own means little;
          of smaller is the share of the smaller cohort that ended up
          in the other, and vs chance is how many times more overlap
          than coincidence would produce. Below 1× means the two cohorts avoid each
          other. Ranked by containment, not by raw count.
        

        

          Needs at least two watchlists on the same chain that share wallets.

          Every token the watched wallets are buying right now — including the ones
          below the signal threshold. All watchlists are pooled into one set
          of wallets, so a token fires when enough of everyone you track has
          bought it; the signal still records which watchlists the buyers came from. A signal only appears once the threshold
          is crossed; this is where you see it building. Two things are excluded:
          arrivals the wallets did not pay for (an airdrop reaches
          thousands of addresses at once and would otherwise look like coordinated
          buying), and tokens with no liquidity pool, which cannot
          be bought or sold at all.

Live distribution (what they are selling)

        
      

      

        

          Everything else here watches money going in. This is the same
          evidence read the other way — and for a token you are already holding on
          a signal, it is the more urgent half. A sale means the token left the
          wallet and something came back in the same transaction;
          a one-way transfer is somebody funding another wallet, not an exit.

Signal scoreboard

        

          
          
        

      

      

        

          Every other number here describes what went into a signal. This is
          the only one that says whether it was right: the price at the moment
          each signal fired, against the price 1 hour, 24 hours and 7 days later. Until
          this table has entries, any threshold you pick is a guess — with it, you can
          change the threshold on evidence.

Research & review

        Off
      

      

        

          Detection stays arithmetic — who bought what, how many, in which window.
          A model is used for the two things arithmetic cannot do. When a
          signal fires, it searches the web and writes three lines on what
          the token actually is, which is the question that otherwise costs you five
          minutes while the entry is still open. On demand, it reads
          the scoreboard and the wallet scores and proposes threshold changes with
          the numbers behind them. It never decides to buy, never sets a threshold,
          and never replaces the contract screen.
        

        

          

            
          

          

            
            
            
          

          

            
            
          

          

            
            
          

          

            

              
              
            

          

          

            
          

          

            
              An OpenRouter key reaches the same Claude models at
              the same list price, and works from places the Anthropic API does
              not. A direct Anthropic key (sk-ant-…) is used instead
              if that is what you paste. Web search for the briefs is billed by
              OpenRouter per result — five per signal.
            
          

        

        

        

        

        

      

    


    
    

      

        
Wallet quality

        

          
          
        

      

      

        

          The pooled signal counts heads — ten wallets bought, so it fires. That
          treats a fund that was four hours early to three tokens that tripled
          exactly like a bot that buys four hundred things a month and is
          occasionally right by accident. This is where you find out which of your
          wallets are which, so you can drop the noise and build cohorts out of the
          rest.
        

        

        

          No watched wallets on this chain yet.
        

        

          

            
          

        

        

      

    


    
    

      

        
Arkham labels

        Off
      

      

        

          Turns an address into who is behind it — “Binance hot wallet”, a named
          fund, a bridge. Useful because an exchange wallet receiving a token is a
          customer deposit, not a conviction buy, and a few of those quietly inflate
          a co-buy count. Get a key at intel.arkm.com → Settings → API
          Keys (access is by application, and calls are metered).
          Arkham reports holders as they are now, so it does not answer
          historical questions — that stays with the Dune sources above.
        

        

          

            
          

          

            
          

          

            
          

          

            
          

        

        

        

      

    


    
    

      

        
Live monitoring (webhooks)

        Off
      

      

        

          The Dune monitor only looks when it is scheduled, so a signal can be up to
          one interval old. With live monitoring, Alchemy pushes every token arrival
          at a watched wallet within seconds of the block and the signal fires
          immediately — and costs no Dune credits. Paste the
          auth token from the top of your Alchemy
          webhooks dashboard (not the app API key) and the public HTTPS
          address of this server, then switch on Live for a watchlist.
          Solana needs a Helius key instead — Alchemy's
          Address Activity is EVM-only — but everything after the decoding is
          shared, so a Solana signal means exactly what an Ethereum one does.
